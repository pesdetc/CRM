Динамический фон с механизмом шестеренок

Прокрутите страницу, чтобы увидеть вращение шестеренок

Как это работает?

Фоновый слой состоит из случайно расположенных шестеренок различных размеров. При прокрутке страницы шестеренки вращаются в зависимости от направления и скорости скролла.

  • Скролл вниз - шестеренки вращаются по часовой стрелке
  • Скролл вверх - шестеренки вращаются против часовой стрелки
  • Скорость вращения пропорциональна скорости скролла
  • Каждое обновление страницы создает новую конфигурацию шестеренок

Технические особенности

Проект реализован на чистом JavaScript без использования внешних библиотек и фреймворков.

  • Использование requestAnimationFrame для плавной анимации
  • CSS transform для производительного вращения
  • Fixed позиционирование фона для эффекта параллакса
  • Адаптивная генерация сетки при изменении размера окна
  • Оптимизированное отслеживание событий скролла

Дизайн и визуал

Каждая шестеренка имеет уникальный дизайн и цветовую схему. Размеры варьируются от 20% до 50% ширины экрана, создавая визуально интересный механизм, напоминающий часовой механизм.

Адаптивность

Сетка автоматически пересоздается при изменении размера окна браузера. Попробуйте изменить размер окна, и вы увидите, как шестеренки перестроятся.

Благодаря использованию CSS transforms и requestAnimationFrame, анимация работает плавно даже с большим количеством элементов на странице.
