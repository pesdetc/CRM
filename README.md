# Динамический фон с механизмом шестеренок

Интерактивный веб-проект с анимированным фоном из вращающихся шестеренок, которые реагируют на скролл страницы.

## 🎯 Особенности

- **Чистый JavaScript** - без фреймворков и внешних библиотек
- **Динамическая генерация** - случайная сетка шестеренок при каждой загрузке
- **Интерактивность** - вращение шестеренок пропорционально скорости и направлению скролла
- **Плавная анимация** - использование `requestAnimationFrame` для 60 FPS
- **Адаптивность** - автоматическое пересоздание сетки при изменении размера окна
- **Производительность** - CSS transforms и оптимизированные обработчики событий

## 🎨 Как это работает

### Генерация сетки

При загрузке страницы:
1. Рассчитывается оптимальное количество шестеренок (8-20) на основе размера viewport
2. Для каждой шестеренки генерируется случайный размер (20-50% ширины экрана)
3. Позиции вычисляются с проверкой на пересечение
4. Случайно выбирается изображение шестеренки из 6 вариантов
5. Устанавливается начальный угол поворота и скорость вращения

### Анимация при скролле

1. **Отслеживание скролла**: событие `scroll` с оптимизацией через `requestAnimationFrame`
2. **Расчет скорости**: дельта между текущей и предыдущей позицией скролла
3. **Применение вращения**: каждая шестеренка вращается с индивидуальной скоростью
4. **Плавность**: использование интерполяции для сглаживания движения

### Направление вращения

- **Скролл вниз** (↓): шестеренки вращаются по часовой стрелке
- **Скролл вверх** (↑): шестеренки вращаются против часовой стрелки

### Адаптивность

При изменении размера окна:
- Запускается debounced обработчик (250ms задержка)
- Сетка полностью пересоздается с новыми параметрами
- Количество и размеры шестеренок пересчитываются

## 💻 Технические детали

### JavaScript класс `GearsBackground`

**Основные методы:**

- `init()` - инициализация системы
- `generateGears()` - генерация сетки шестеренок
- `calculateNumGears()` - расчет оптимального количества
- `generateNonOverlappingPositions()` - алгоритм размещения без пересечений
- `isPositionValid()` - проверка валидности позиции
- `createGearElement()` - создание DOM элемента шестеренки
- `setupEventListeners()` - настройка обработчиков событий
- `updateScroll()` - обновление состояния при скролле
- `startAnimation()` - запуск цикла анимации

### CSS особенности

- `position: fixed` для фонового контейнера
- `will-change: transform` для оптимизации
- `backdrop-filter: blur()` для эффекта размытия контента
- Низкая `opacity` (0.15) для шестеренок, чтобы не перегружать визуал

### Оптимизации производительности

1. **Passive listeners** - для событий скролла
2. **RequestAnimationFrame** - для синхронизации с частотой обновления экрана
3. **Debouncing** - для события resize
4. **CSS transforms** - аппаратное ускорение
5. **Will-change** - подсказка браузеру для оптимизации

## 🎨 Кастомизация

### Изменение количества шестеренок

В методе `calculateNumGears()`:

```javascript
const baseGears = 12; // Базовое количество для Full HD
numGears = Math.max(8, Math.min(20, numGears)); // Минимум и максимум
```

### Изменение размеров шестеренок

В методе `generateGears()`:

```javascript
const minSize = viewportWidth * 0.20; // 20% от ширины
const maxSize = viewportWidth * 0.50; // 50% от ширины
```

### Изменение скорости вращения

В методе `generateNonOverlappingPositions()`:

```javascript
position.rotationSpeed = this.randomRange(0.5, 2.0); // Диапазон скорости
```

В методе `updateScroll()`:

```javascript
const rotation = delta * rotationSpeed * 0.5; // Множитель общей скорости
```

### Изменение прозрачности шестеренок

В `css/styles.css`:

```css
.gear {
    opacity: 0.15; /* Значение от 0 до 1 */
}
```

### Добавление своих изображений

1. Создайте SVG или PNG изображение шестеренки (квадратное, 1:1)
2. Сохраните в папку `assets/gears/`
3. Добавьте путь в массив `gearImages` в `js/gears.js`:

```javascript
this.gearImages = [
    'assets/gears/gear1.svg',
    'assets/gears/gear2.svg',
    // ... добавьте свой файл
    'assets/gears/my-custom-gear.svg'
];
```
